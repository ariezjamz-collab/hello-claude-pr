# Cinematic Stories

Two cinematic looks for Instagram stories, made from the chai-street night photos.

| File | What it is |
|---|---|
| `Story1_*.jpg`, `Story2_*.jpg` | Finished stories, 1080×1920 (9:16), ready to post |
| `Cinematic_Teal_Amber.xmp` | Classic film look: teal shadows, amber lights, faded blacks, muted greens, light grain |
| `Cinematic_Golden_Noir.xmp` | Darker look: deep blacks, golden lights, olive greens, muted blues, stronger vignette and grain |

**Import in Lightroom mobile:** open a photo → **Presets** → **⋮** → **Import Presets** → choose `Cinematic_Story_Presets.zip`. The presets appear in the group **Cinematic Stories**.
Then **Crop** → **9:16** for a story.
